# Home's sky: the build plan

The plan for building the signed-off sky, "the painted hill", in SwiftUI. Read this first if you
are picking the work up. It was written on 22 Nov 2026 from five read-only maps of the code
(`docs/sky-build/`), revised after an adversarial review, and amended below for what has been
decided and built since.

- **The design** is a browser mockup: `design/sky-lab/` ("the lab"). Its brief and every decision
  are in `design/sky-lab/BRIEF.md`; **the subsection "Signed off" wins** over everything before
  it. The sky itself is `design/sky-lab/skies/hill-painted.js`, and its notes, with a "SwiftUI
  port" section, are `design/sky-lab/skies/hill-painted.md`.
- **What it should look like**: run the lab (below), or ask the owner for the gallery page of
  stills and films (a private page; it is linked from pull request #301).
- **The work so far** is on branch `claude/trusting-ptolemy-jz35il`, draft pull request #301.

## Rules of the road

- **Never push to `main` and never push a `v*` tag.** Every merge to `main` is archived by Xcode
  Cloud and delivered to both parents' phones by TestFlight; there is no feature flag system.
  Work on the branch; the pull request stays a draft until the owner says otherwise.
- **The new sky ships dark.** Until the last stage it sits behind a device-local switch
  (`LocalPrefs`, a row in Settings → Data beside Demo mode) that is off by default, and
  `SkyBackground` and Home keep working exactly as they do today.
- **Nothing is stored and no CloudKit schema changes.** Whether Home looks up is worked out from
  the clock, the sun and the sleep log.
- **The tests compare the Swift with the lab, not with itself.** `TwoOfUsTests/SkyCoreFixtures*.swift`
  are generated by `design/sky-lab/tools/swift-fixtures/*.mjs` (read that folder's README; every
  exporter has `--check`). Never edit a fixture by hand, never loosen a tolerance without saying
  why in the test, never skip a test to get green.
- **The new files must not be referenced from files shared with the widget, watch or notification
  targets**: those targets list their sources one by one in `project.yml`.
- **Judge pictures by looking**, at the size a parent sees, against the lab's frames. The
  signature frame is the closed Duo, dark, 21 Nov 4:10 pm: the tree against the setting sun
  (`day/cover-dark-1610` in the lab's review set).

## Building and testing

On a Mac, from the repository root (`project.yml` → XcodeGen; the simulator is "iPhone 17"):

    make project      # regenerate TwoOfUs.xcodeproj
    make build
    make test         # TwoOfUsTests on the simulator; the new tests are among them

On Linux (no Xcode; the pure layer only), with Swift for Linux at `/opt/swift`:

    scripts/sky-core-linux-test.sh                      # everything
    scripts/sky-core-linux-test.sh --filter NightRuleTests

It builds a scratch SwiftPM package outside the repository: `TwoOfUs/Sky/Core/*.swift` with
`Store/SolarClock.swift` and `Store/MoonClock.swift` as a module named `TwoOfUs`, and the matching
test files, in Swift 5 mode.

The lab runs in any browser from `design/sky-lab/` (see its `README.md`). Its tools need Node 22
and Playwright with Chromium where `require('playwright')` can find it; there is no
`package.json`, so on a new machine install Playwright somewhere on `NODE_PATH`. From
`design/sky-lab/`:

    node tools/test-math.mjs                                   # the lab's own maths, 80 tests
    node tools/review.mjs --sky hill-painted --out <dir>       # the review stills
    node tools/film.mjs --sky hill-painted --event bedtime --out <path>   # a moment as a film
    node tools/measure.mjs --sky hill-painted --quiet          # the legibility gates

## 1. ARCHITECTURE

**Five choices**

1. **One sky view, hoisted out of the list.** `HillSky` replaces both of today's skies (HV:461-464, HV:610-611). It is the first child of body's ZStack (HV:171), under the phone page's own condition (HV:180): one clock, one driver, no seam.
2. **Painted layers are Core Graphics bitmaps made off the main thread**, in a 16-bit context, dithered once to 8-bit sRGB. It is a re-drawing, not a copy: HP has 11 `filter: blur()` sites, which become Accelerate passes on quarter-size buffers.
3. **The sky field is a shader:** a `colorEffect` over a small OKLab texture on the lab's 2 pt grid, with hush and room depth as uniforms ahead of the dither (MD:1155-1156). If a `.metal` file will not build under XcodeGen: a CPU image, and no bloom.
4. **Time is data.** Every moving value is a pure function of (now, inputs, event start times). SwiftUI's animations drive only the cards.
5. **The lab exports geometry and numbers, not pictures:** the tree's skeleton (TREE:59), crest and cloud tables, star places, sampled curves.

**Files.** `TwoOfUs/Sky/Core/` is Foundation only; `TwoOfUs/Sky/` renders. No widget or watch file may reference either (those targets list files one by one, per the maps).

## 2. THE PURE LAYER

```swift
extension SolarClock {
  static func position(at: Date, latitude: Double, longitude: Double) -> (altitude: Double, azimuth: Double)
  static func rises(through degrees: Double, after: Date, latitude: Double, longitude: Double) -> Date?
}
struct SleepSpan: Equatable { let id: UUID; let start: Date; let end: Date? }
enum NightRule { static func state(at: Date, sleeps: [SleepSpan], place: SkyPlace, policy: Policy, calendar: Calendar) -> NightState }
struct NightState: Equatable { let frame: NightFrame?; let begunBy: SleepSpan?; let running: SleepKind? }
enum NightCount { static func night(at: Date, born: Date, place: SkyPlace, calendar: Calendar) -> Int }
enum SkyBodies { static func drawn(altitude: Double, xFraction: Double, radius: Double, look: Double,
                                   world: SkyWorld, layout: SkyLayoutModel, dark: Bool) -> BodyDraw } // place, disc, halo, dimmed
enum StarChart { static func cast(nights: Int, monthNights: Set<Int>, world: SkyWorld, layout: SkyLayoutModel) -> [Star] }
enum SkyCamera { static func offset(of: Plane, look: Double, tilt: CGSize, scale: Double, world: SkyWorld) -> CGSize }
enum Moment { static func frame(age: TimeInterval, world: SkyWorld.Kind, reduced: Bool, endedAt: TimeInterval?) -> MomentFrame }
struct Glide { func value(at: Date) -> Double; func retargeted(to: Double, at: Date, over: TimeInterval) -> Glide }
enum SkyScript { static func step(from: NightState?, to: NightState, hand: HandStart?, playedTonight: Bool, now: Date) -> SkyEvent? }
```

**The night rule**
- **Night sleep:** local start in 18:00 to 04:00 (BRIEF:238-241; "the 6 pm rule stands", BRIEF:361). Not ported: the lab's "sunset if earlier" (CORE:306-318). `Policy` holds the hours.
- **Frame:** 18:00 until the sun next rises through −7° (CORE:300); 04:00 where it never gets that low.
- **Begun:** the earliest live night sleep that started in the frame before `min(04:00, first light)`. Ended sleeps count, so a night feed changes nothing. A start ahead of this phone's clock counts at once.
- **It still disagrees with the app:** the wording rule calls a start before 20:00 a nap (`APP/TwoOfUs/Store/SleepLanguage.swift:16-17`, per the maps). Decision 1.

**Night N** = calendar days from `startOfDay(born)` to the night's evening day, + 1. **It turns when the rising sun passes −4°**, not at first light. At −7° a third of the stars' light is still out (0.32 by the formula at PRES:182), and a turn there would pop last night's star into the settle. Month-nights use real month-birthdays (NIGHTS:34-36).

**Sun and moon (`SkyBodies`)**, as round two drew them, because the sign-off says "as in round two" (BRIEF:362-366):
- `seen`: no disc in the Duo's header band, none behind the slab's status bar (HP:785-796);
- `clearOfText`: in dark, behind the words, no halo and a dimmed disc (HP:1049-1059, 4052, 4071);
- `clearOfButtons`: no disc behind the avatar or the gear (HP:1063-1073);
- `underIcons`: no disc in the strip beside the status icons until its top is 16 pt clear (HP:3963-3980). This is the sign-off's kept exception (BRIEF:368-370).
- **Not ported:** `standsOpen` (HP:1127-1145, 4009, 4080) and the quartered halo (HP:4032). **No function here takes a card.**

**`SkyScript`**
1. The first evaluation after Home appears or becomes active plays nothing.
2. The night begins with this phone's hand token, and the moment has not played tonight: `bedtime`.
3. The night begins any other way: `arrive` if that sleep started within 90 s of now; otherwise a 0.6 s dissolve.
4. First light: `settle`.
5. Un-begun by an undo, a delete or an edit: wait 1.5 s, then `settle` if still un-begun. A local Undo skips the wait.
6. It keys on the derived fact, never on a sleep id: edits change ids (ES:602-616).

"Played tonight" is in memory, set once the caption is up (2.8 s), so a mis-tap undone at once does not spend the moment.

## 3. RENDERING

| Element | Technique | Made | Per frame |
|---|---|---|---|
| Sky field | shader over a 2 pt OKLab texture | each minute key | two uniforms |
| Land planes, river, snow | CG painters; each plane cropped to what can show | each minute key | offset |
| Tree | cut in Swift from the exported skeleton | each season step; tint each minute | offset, opacity |
| Clouds, mist | CG masks from the lab's contour tables, tinted | each minute | offset |
| Sun, moon, halos, glare, text guards (HP:3713-3756) | sprites; no blur per frame | each minute | place and strength from `SkyBodies` |
| Stars, tonight's star, fireflies, leaves, snowfall | one `Canvas` | cast once per night and layout | see policy |
| Band | `Canvas` gradients, drawn small | — | 2.1–4.2 s of the moment |
| Caption | `Text` | | |

- **The tree is not shipped as images.** Its masks have about 180 season states a year (run; keyed at HP:4304), up to 19 masks each (MD:1132-1136). Swift ports the mask cutter (TREE:421-833): bare, frost and snow first; leaf and blossom (TREE:478, 625) before April.
- **Looking up is only a slide.** Each plate gets `SkyCamera.offset`; tonight's star is a lerp between two homes (HP:692-699). Nothing repaints for a move.
- **One world, three displays.** Cover and spread share the Duo world; the cover is the spread's phone-page tile. The slab is its own authored world.
- **Tone, decided.**
  - The sky follows the lab's hush and depth exactly, by uniforms.
  - Land, tree and clouds hold their tone while they slide, then cross-fade once to the dimmed painting, from the end of the rise to 9 s (the lab dims from 1.2 s, PRES:152).
  - New fades in over old at full opacity; a symmetric fade would show a quarter of the sky through the hills.
  - The land does not swell with an event's bloom in the first build (decision 5).
- **Before the first plates, and after an appearance flip:** a three-stop wash from `Air`; plates fade in over 0.3 s.
- **Tilt and scroll parallax (BRIEF:33) are not built.** `SkyCamera` keeps the parameter.

**Memory budget** (arithmetic, not measured): 40 MB of plates at rest, 80 MB during a cross-fade, on any display at 3×. Uncropped, one spread set would be about 110 MB (the sky alone: 3441 × 1980 × 4 bytes = 27 MB). Means: the sky as a texture; cropped planes; reused buffers; while the Duo is closed, the leading half kept at 1× and sharpened on opening. If still over, far, mid and knoll become one plate: they travel identically (HP:128-141).

**Frame-rate policy**

| Clock | Runs | Rate |
|---|---|---|
| Minute | while Home is visible and active | 1 per minute; a new painting fades in over 1 s |
| Alive (twinkle, mist, fireflies) | night, or mist by day | 10 fps; 30 while snow or leaves fall |
| Event | only while a `Glide` or the moment runs | 60 |

- **60, not 120:** `CADisableMinimumFrameDurationOnPhone` is in neither `APP/TwoOfUs/Info.plist` nor `APP/project.yml`. Adding it changes the whole app; not proposed.
- **Low Power Mode:** the alive clock stops; events still play. **Thermal serious:** moves become the 0.6 s dissolve. **Not active:** nothing runs; the pose snaps on return.
- **The moment's clock starts at the first sky frame after the driver sees the night begin**, not at the tap, which saves, starts the Live Activity and reloads widgets on the main thread (ES:463-491).

## 4. HOME INTEGRATION

- **The hook.** `HomeView.startSleep()` (HV:2488-2493): after the store returns the event, `skyDriver.startedByHand(event.id)`; its Undo closure also calls `skyDriver.undid(event.id)`. The token lives in memory for 5 s.
- **Cards step back, one by one.**
  - The driver owns the flag. `CardVeil` fades each card inside its row: the Today card, each tile, the sleep card, the SNOO and schedule rows (HV:407-426), the checklist (HV:444), and the timeline's rows with their row backgrounds (HV:2907-2941).
  - Curves: `.easeInOut(1.0)` out, `.easeOut(1.2)` back (MD:1208-1212). The sky reads the same curve from `Moment`.
  - **The header row stays** (HV:382): name, age, avatar, gear. The lab keeps it outside the veil (`LAB/lab/chrome.js:748-749`).
  - **Not one opacity on the list:** the lab's author found that glass then loses the sky and jumps (`LAB/lab/chrome.css:1140-1143`). How a glass tile leaves is a spike's answer.
  - **The leading page** fades whole, title and cards, by one opacity on `spreadDetailsPage` (HV:614), as in the lab's films (FILM:26-28, 114). It has no glass (per the maps).
- **A touch ends it.** A clear catcher over the list, under the toast, live only during the moment: cards back in 0.3 s, band and caption out in 0.2 s, `look` untouched (MD:1212-1216). Undo sits above the catcher, so `undid` ends the moment the same way and the view settles.
- **Quiet rise, first light.** `arrive` is 2.5 s behind the cards; `settle` is 0.1–2.7 s (HP:653-666). Each is a `Glide` retarget, so an event during another eases from where the value is.
- **Opening the Duo.** Home derives a pose (cover, spread, other) from the reader (HV:164-170, 188). The cue fires only from cover to spread: turning an open Duo also makes `grid` non-nil. The driver holds the leading page at 0 while closed, so it mounts bare; cards land at 0.9–1.9 s (FILM:116).
- **Rects, without layout loops.**
  - `SkyLayoutModel` computes scroll-top rects from the app's constants. The name's width is computed from the font, not measured.
  - Live rows come from `onGeometryChange` (precedent HV:469-500) into `SkyLayoutStore`. Only the sky reads it, and the sky is in no measured view's layout.
  - **The island is always taken as long.** Live Activities can be off (`APP/TwoOfUs/LiveActivities/SleepActivityManager.swift:154`), so "asleep" does not mean a long island. The lab's 0.6 s join (HP:305-308) is then not needed.
- **The cards cut the sun and the moon.** The sky draws a disc by `SkyBodies` and never asks where a card is.

## 5. ACCESSIBILITY AND SETTINGS

- **Reduce Transparency, Increase Contrast:** flat `AppColor.bg`, nothing painted, no moment (SB:89-90).
- **Reduce Motion:** the `reduced` table (PRES:94-100); `arrive` and `settle` are a 0.6 s dissolve. No twinkle, band, spark or drift.
- **VoiceOver:** the sky stays hidden. The cards do not step back; the view rises quietly and "Night 143" is announced.
- **Dynamic Type:** the caption uses a scaled `AppFont`; star keep-outs use the computed name width, rounded to 4 pt.
- **Gates as code:** `testTheSkyStaysLegible` on the air table, and `HillSkyGateTests` on **the whole composite** (plates, discs, halos, glare, guards), put together in Core Graphics by the same placement functions, at 2× and 3×. Discs and points of starlight are exempt.

## 7. DATA
